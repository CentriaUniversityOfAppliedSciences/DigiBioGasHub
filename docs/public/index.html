What is DigiBioGasHub?

DigiBioGasHub is a marketplace for biogas related products and services. It is a community for biogas enthusiasts, industry players, farmers, and researchers.

groups

Community

The platform is built for the community. It has chat feature for networking with the community.

storefront

Marketplace

Users can create offers or ask for products and services in the platform.

news

Articles

Platform admin can create articles for the community. Articles can be used to share knowledge and news about biogas. Platform provides easy-to-use WYSIWYG editor for creating articles.

analytics

Analytics

Platform provides analytics features for the community. Users with companies can access data their data and insights about biogas related products and services.

explore

Map

Map feature will be used to show biogas related products and services on the map. Users can find offerings, companies or services near them.

chat

Chat

Chat feature is used for networking with the community. Users can chat with each other and share knowledge.

search

Search by DocSearch

Search your docs with DocSearch. A powerful, efficient and accessible search solution built on Algolia Crawler & Autocomplete.

translate

Multilingual Support

The platform is available in Finnish, Swedish, and English. Users can choose their preferred language in the platform. Developers can add more languages to the platform.

code

Open Source

DigiBioGasHub is an open source project. The source code is available on GitHub. Developers can contribute to the project and help to improve it.
