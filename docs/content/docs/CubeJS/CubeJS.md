CubeJS (https://cube.dev/) is used to create analytics for the platform. It is used in combination with ApexCharts (https://www.apexcharts.com/docs/vue-charts/) to show analytical graphs.  

Docker compose in repository uses non-avx version of cubestore. This version works in VirtualBox environment.
